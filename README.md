# Vision AI ZION — Template Empresário

Este repositório é um template pronto para usar o framework ZION da Vision AI no Claude Code Web.

## Como usar

1. Clique em **"Use this template"** no topo desta página
2. Crie sua cópia em uma conta GitHub sua
3. Abra https://claude.ai/code
4. Crie nova sessão escolhendo este repo recém-copiado
5. Na primeira mensagem, ZION estará ativo. Digite `/agents` para ver todos os 16 agentes

## O que vem ativo

- 16 agentes especializados Vision AI
- 22 skills proprietárias
- Routines (automações 24/7) disponíveis após instalação

Lista completa: https://github.com/Douglas8832/zion
